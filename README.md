# Roadmap DevOps 2027

Curso abierto en español para aprender DevOps de cero a profesional, en 11 fases: Linux y redes,
contenedores, CI/CD, AWS, IaC, Kubernetes, GitOps, observabilidad, DevSecOps, Platform Engineering
e IA en DevOps.

**Ábrelo aquí: https://amilcar-steban.github.io/roadmap-devops-2027/**

Cada fase trae teoría explicada desde cero, diagramas, comandos para Windows, macOS y Linux,
laboratorios, autoevaluaciones y un kit descargable que hace crecer el mismo proyecto: una tienda que
pasa de un servidor Linux a una plataforma en Kubernetes con su agente de guardia.

Antes de empezar: 16 GB de RAM, unos 40 GB libres, Docker y una cuenta de GitHub. Los laboratorios en
AWS usan tu cuenta y cuestan dinero (cada fase lo avisa). Tu progreso se guarda en tu navegador.

Las soluciones de referencia del proyecto:
